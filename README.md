这个 Skill 用来检查团队共享的自动化工具。目前交付的是演示版，还不能直接安装到 Dots 后用于日常工作。正式接入由交付方完成，公司同事无需自行安装软件或操作代码。

一个工具在 A 的电脑上能用，到了 B 那里，可能缺少配套软件、文件或账号权限。这个 Skill 把交接前的检查固定下来，减少大家反复找作者排查问题，也避免把没有验证过的工具直接用于日常工作。

正式接入云电脑后，使用流程是：

1. 同事上传工具，说明它用来做什么，并提供一份样例。例如，一张需要处理的表格，以及处理后应该是什么样。
2. 系统检查运行条件，在云电脑上完整试跑一次，核对结果。
3. 通过验证的工具加入“白名单”，也就是团队可以调用的工具列表。
4. 没通过的工具保持停用，并说明原因；修改后重新验证。

工具内容或运行环境变化后，也需要重新验证。这样，团队能知道哪些工具在指定环境里已经跑通。测试通过只覆盖已验证的用途，重要业务结果仍需按原有工作要求核对。

正式开放后，同事只需选择已通过检查的工具，提供要处理的材料。未通过检查的工具会保持停用；需要修改程序或调整配置的问题，由交付方协助处理。

演示版已用示例工具跑通“上传、自动验证、加入白名单、调用和停用”。正式使用还需要接入实际 Dots 云电脑，并验证一个真实工具。公司同事只需提供这个工具、一份样例，以及对结果的要求；交付方负责完成配置和验证后再交付使用。
