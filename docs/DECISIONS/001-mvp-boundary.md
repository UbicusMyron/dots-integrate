# Decision: 首期聚焦轻量依赖核查与试运行

Last Reviewed: 2026-10-12

## Status

首期交付范围已由用户确认；外部架构为继承的设计前提，尚无实测证据。

## Context

2026-10-12 读取「dots云端共享」（thread id `01a12f85-c0b2-7032-9a3c-4ba3834fbfd3`）。其中用户要求只处理最大瓶颈、避免超前优化，并将系统兼容性降为普通检查项。这里保存必要决定，后续实施无需读取原聊天。

## Decision

- 用户本轮选择：“做轻量的依赖核查与试运行 Skill／脚本，用一个真实工具验收”。
- 用户本轮确认暂无真实样本；批量上架只是先前举例，不能认定为已选试点。
- 继承用户提出的 Dots 运行、Mac Mini 保管业务 API 密钥并代调、Drive 文件持久化方案。
- 继承单一公共运行环境的意图，不规划多套长期环境。
- 初始治理时 Python 版本未定；随后用户要求设定兼容性优先的云端依赖环境，现采用 CPython 3.12 系列和常用办公核心依赖，初始构建候选为 3.12.15。具体规范见 `docs/RUNTIME.md`；目标环境联测与完整锁定仍未完成。
- 当前只生成治理；不实现、部署或调用业务接口。

## Reversibility

- Classification: 文档组织和内部报告可逆；生产鉴权、网关协议与业务数据迁移不在本轮决定内。
- Human confirmation required: 首期范围已确认，无需重复；未来扩大高影响范围按 AGENTS 执行。
- Why: 当前不能根据一个没有样本的规划锁死生产接口。

## Consequences

- 可以先开发静态盘点基础，真实工具缺失不阻塞这一独立任务。
- 真正的项目验收必须等真实工具、目标环境及业务预期齐备。
- 治理采用精简 Standard 文件结构。安装的 constitution 无 flash 子模式，本轮将 flash 理解为快速收敛、少问关键问题，不虚称使用了不存在的流程。

## Alternatives Considered

只交接一个现有工具：用户本轮选择了更可复用的轻量 Skill／脚本。
通用发布平台：与当前瓶颈不匹配，排除首期。
